Gestion des erreurs de signature

Analyse le code source afin de déterminer le comportement du moteur SABR lorsqu’une erreur de signature est détectée.

Précise notamment :

* Dans quelles conditions une erreur de signature peut survenir et à quel niveau elle est détectée.
* Quel composant effectue la vérification de la signature.
* Quel traitement est déclenché lorsque la signature est invalide.
* Si le traitement en cours est interrompu, rejeté ou poursuivi.
* Quel code d’erreur ou message de réponse est généré.
* Comment l’erreur est propagée et communiquée aux autres composants.
* Si des mécanismes de journalisation, de reprise ou de nouvelle tentative sont prévus.

Important : distingue les traitements réellement effectués par le moteur SABR de ceux réalisés par le simulateur. Appuie chaque affirmation sur les classes et méthodes concernées. Si le comportement du moteur n’est pas visible dans le repository, indique explicitement qu’il ne peut pas être déterminé à partir du code disponible, sans inventer de fonctionnement.
